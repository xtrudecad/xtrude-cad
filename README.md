# Xtrude CAD

**Precise technical 3D modeling for 3D printing** — robot parts, brackets,
enclosures, PCB mounts, servo horns — with *push/pull* modeling, as a native
Rust application. Website: <https://xtrudecad.org>.

> [!NOTE]
> **The source code is not published yet.** Xtrude CAD is under heavy
> development and testing. The code will be published here with the first
> public release, very soon.
>
> Watch this repository (**Watch → Custom → Releases**) to be notified when
> it is out.

## Origin

Xtrude CAD is derived from [IngeTrazo](https://github.com/ingelibre/ingetrazo)
by Marco Sumari Tellez and the IngeTrazo contributors, rewritten in native
Rust. It will be released under the [GPL-3.0-or-later](LICENSE) license.
